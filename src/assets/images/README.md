# Sprite files

One transparent PNG per registered asset, named by asset id (e.g. `product.soda.png`), at 4× the asset box
plus 2 px padding. Generated by `npm run art:export` from the procedural art; repaint freely at the same size.
See `docs/ART.md` → Asset files. Sprite sheets live in `../sheets/`, terrain textures in `../textures/`.
